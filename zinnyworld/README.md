# ZinnyWorld (Planning Repo Scaffold)

This folder is a **new project scaffold** for the ZinnyWorld hair e-commerce platform requested by the client.

Current scope in this commit:
- Clickable wireframe (HTML/CSS, static)
- Product and technical specification (pre-coding)
- Initial data model and API-ready architecture notes

> No PHP/MySQL application code has been implemented yet. This is the pre-development planning package.

## Open the wireframe

- File path: `wireframes/index.html`
- You can serve this folder with any static server, for example:

```bash
cd zinnyworld
python3 -m http.server 8080
```

Then open: `http://localhost:8080/wireframes/index.html`.

## Brand direction
- Name: **ZinnyWorld**
- Palette: `#000000`, `#DFB011`, `#DBBB5F`
- Tone: Luxury/premium + affordable/everyday

## MVP feature intent
- Catalog: wigs, frontals, closures
- Variant matrix: length, texture, density, lace, color
- Inventory tracked by variant
- Guest checkout + encouraged registration
- Payments: PayPal and bank transfer
- Shipping: Australia (primary), Nigeria (bundles occasionally)
- Admin dashboard: products/orders/customers/stocks/reports
- Reviews/ratings, discount codes, low-stock alerts
